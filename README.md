# Registration Form
A clean, modern, and minimal Registration Form web layout built using structured HTML5 and custom CSS3. This project showcases semantic form structures, dark-themed input layouts, and fully responsive input field configurations.

## Features
* **Clean UI Layout:** Features a dark slate background with a high-contrast deep blue input field grid.
* **Visual Enhancements:** Includes custom fieldset section dividers and fluid responsive spacing adjustments.
* **Interactive Effects:** Features explicit input typography styling and clean form submission button outlines.
* **Clean Structure:** Uses precise semantic block elements to ensure structural alignment across devices.

## Tech Stack
* **HTML5:** For core form controls, specialized input types, choice selection menus, and bio textareas.
* **CSS3:** For deep color themes, explicit dimension constraints, semantic viewports, and unified typography blocks.

## What I Learned
* Customizing standard form elements and text regions using custom dimension constraints.
* Implementing explicit border dividers across multiple fieldsets inside an aligned web view.
* Structuring nested control components like inline choice buttons and file upload inputs cleanly.
